# Contributing to FrankBase Transparency Ledger

We welcome community inspection, mathematical audit reports, and architectural feedback.

## Reporting Issues
- If you notice a checksum mismatch or corrupted JSON entry, open a GitHub Issue with full details.
- For security or PII concerns, email [legal@frankbase.com](mailto:legal@frankbase.com) or [connect@mastermanikant.com](mailto:connect@mastermanikant.com) directly.

## Attribution
When referencing this architecture or utilizing its schema in your own projects:
- Maintain original copyright and attribution notices.
- Adhere strictly to the Trademark Guidelines in `TRADEMARK.md`.
