# 🔐 Security & Vulnerability Disclosure Policy

## Responsible Disclosure Standard
The FrankBase Ecosystem is committed to 100% transparency, data privacy, and secure engineering. We welcome responsible security reports from the global research community.

## Reporting a Security Issue
If you discover a potential vulnerability, cryptographic weakness, or accidental PII exposure:
- **Primary Security Desk:** [legal@frankbase.com](mailto:legal@frankbase.com)
- **Executive Desk:** [connect@mastermanikant.com](mailto:connect@mastermanikant.com)

Please include:
1. Clear description of the vulnerability.
2. Step-by-step reproduction guide or proof-of-concept (PoC).
3. Any affected URLs, endpoints, or data payloads.

> [!IMPORTANT]
> **Strict Personal Privacy Invariant:** Never publish, leak, or broadcast unmasked personal customer data or private keys. Reports handled in good faith will receive prompt acknowledgment within 24–48 hours.

## Safe Harbor Guarantee
Security researchers conducting authorized, non-destructive testing in compliance with this policy will not face legal action.
